# Segundo Cérebro em Business Intelligence

## Objetivo

Criar um segundo cérebro especializado em Business Intelligence,
Power BI, análise de dados e visualização de informações para
apoiar estudos e tomada de decisão baseada em dados.

## Fontes Utilizadas

- Microsoft Learn Power BI
- Power BI Documentation
- Tableau Data Visualization
- Looker Documentation

## Por que confio nessas fontes?

As fontes escolhidas são documentações oficiais e materiais de referência
mantidos por empresas líderes do mercado de análise de dados e Business
Intelligence.

## Diretriz Utilizada

Comporte-se como um especialista em Business Intelligence,
Power BI, análise de dados e visualização de informações.

Responda exclusivamente com base nas fontes fornecidas e
sempre cite de qual fonte a informação foi retirada.
